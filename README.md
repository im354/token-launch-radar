A token launch radar for make.fun's token-radar-01 bounty: it ranks every pre-token protocol in the sealed snapshot by a category-anchored implied value, then gives each one a costed, step-by-step farm plan. The dashboard is a static page that reads the board it writes, with filters, per-protocol model breakdowns and the airdrop math stated as an assumption, and no network calls.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input
```
